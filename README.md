## 📋 نبذة عن المشروع

**Alisha** هو تطبيق ويب تفاعلي يعمل كمساعد ذكاء اصطناعي مع أفاتار Live2D ثلاثي الأبعاد. يتميز التطبيق بقدرته على إجراء محادثات صوتية كاملة مع حركة متزامنة للشفاه، ويدعم 8 مزودي مختلفين للذكاء الاصطناعي، و3 لغات (العربية والإنجليزية واليابانية). يوفر التطبيق مفاتيح API مجانية مُحدّثة تلقائياً من GitHub مع تبديل تلقائي عند نفاد الحصة.

## ✨ المميزات الرئيسية

### 🔑 مفاتيح مجانية تلقائية
- جلب تلقائي لأول 10 مفاتيح مجانية متاحة من GitHub
- تنوع في الفئات: GPT، Claude، Gemini، DeepSeek، والمزيد
- تبديل تلقائي عند نفاد حصة المفتاح (حتى 5 محاولات)
- إمكانية إدخال مفتاح API يدوي كبديل
- **حفظ دائم**: الإعدادات والمفاتيح محفوظة حتى بعد إغلاق المتصفح

### 🎙️ محادثة صوتية كاملة
- جميع الردود صوتية - الأفاتار يتحدث بالصوت
- إدخال صوتي عبر التعرف على الكلام (Web Speech API)
- ردود صوتية طبيعية عبر توليد الكلام (Web Speech Synthesis + Google TTS احتياطي)
- إدخال نصي كبديل عند عدم توفر الميكروفون
- إمكانية إيقاف الصوت الحالي

### 🎭 أفاتار Live2D تفاعلي
- 4 حالات للأفاتار: ساكن، يستمع، يفكر، يتكلم
- **تزامن كامل** بين حركة الفم والصوت الفعلي
- حركة تنفس طبيعية في حالة السكون
- حركة إيماءة بالرأس أثناء الاستماع
- إمالة الرأس أثناء التفكير

### 🔍 التحقق من المفتاح والموديل
- زر "اختبار" في الإعدادات للتحقق من أن المفتاح والموديل يعملان
- رسائل واضحة عند فشل التحقق (مفتاح منتهي، موديل غير متاح، إلخ)

### ⚙️ إعدادات شاملة
- **تغيير المفتاح**: عرض المفاتيح المجانية + المفاتيح اليدوية + إدخال جديد
- **تغيير الموديل**: قائمة بجميع الموديلات المتاحة مع بحث
- **لغة الرد**: عربي، إنجليزي، ياباني
- **30 خلفية أنمي**: ساكورا، مجرة، غابات، قلاع، تحت الماء، وأكثر
- **ذاكرة دائمة**: تعليمات مخصصة تُقرأ في كل محادثة
- **ذاكرة المحادثة**: عرض ومسح رسائل المحادثة الحالية

### 🌍 8 مزودي API
التطبيق يدعم المزودين التاليين مع **اكتشاف تلقائي** لنوع المفتاح:

## 🚀 طريقة التشغيل

### المتطلبات
- Node.js 18+
- npm

### التثبيت والتشغيل

```bash
# استنساخ المشروع
git clone https://github.com/magengillan00-lgtm/Alisha.git
cd Alisha

# تثبيت الحزم
npm install

# تشغيل بيئة التطوير
npm run dev
```

افتح المتصفح على `http://localhost:3000`

### بناء APK (Android)

```bash
# بناء المشروع كملفات ثابتة
npx next build

# إضافة منصة Android
npx cap add android

# مزامنة الملفات
npx cap sync android

# بناء APK
cd android && ./gradlew assembleDebug
```

سيكون ملف APK في: `android/app/build/outputs/apk/debug/app-debug.apk`

## 🔧 كيف يعمل النظام

### تدفق التطبيق
1. عند الفتح: عرض أول 10 مفاتيح مجانية متاحة
2. المستخدم يختار مفتاحاً (أو يدخل مفتاحه يدوياً)
3. عرض الموديلات المتاحة للمفتاح المختار
4. المستخدم يختار موديلاً وتبدأ المحادثة
5. الأفاتار يتحدث بالصوت - جميع الردود صوتية

### تبديل المفاتيح التلقائي
عند نفاد حصة المفتاح الحالي:
1. النظام يحاول التبديل للمفتاح التالي المتاح
2. يتم تحديث الموديل تلقائياً إذا اختلف
3. يظهر إشعار بالتبديل
4. بعد 5 محاولات فاشلة: رسالة خطأ واضحة

### الحفظ الدائم
- المفاتيح والإعدادات محفوظة في localStorage
- عند إعادة فتح التطبيق: ينتقل مباشرة للمحادثة إذا كان هناك مفتاح وموديل محفوظان
- يمكن تغيير المفتاح والموديل من الإعدادات في أي وقت
